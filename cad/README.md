# CAD-модель сектора центробежного колеса (восстановлена по `CBK_2_gor_222.stl`)

## Файлы
| Файл | Содержимое |
|---|---|
| `CBK_2_gor_222_sector.step` | Твердотельная модель сектора: полотно + основная лопатка + укороченная лопатка + галтели (1 тело, 14 граней) |
| `CBK_2_gor_222_blades_fillets_surfaces.step` | Только поверхности: 2 лопатки (бок. поверхность, торец периферии, срез выходной кромки) и 2 галтели (8 граней) |
| `preview.png` | Вид модели (синий — лопатки, оранжевый — галтели, красный — срез выходной кромки, зелёный — торцы) |

Формат STEP AP214, единицы — **мм**. Положение совпадает с STL (координаты STL интерпретированы как метры и умножены на 1000).
Ось вращения колеса — глобальная ось **X**.

## Имена граней (в STEP)
`Hub_Front`, `Hub_Back`, `Hub_InletRound`, `Hub_Rim`, `Hub_PeriodicSide` ×2,
`Blade_Main`, `Blade_Main_Tip`, `Blade_Main_TE_Cut`, `Fillet_Main_R2.5`,
`Blade_Splitter`, `Blade_Splitter_Tip`, `Blade_Splitter_TE_Cut`, `Fillet_Splitter_R2.5`.

Галтели — отдельные грани (B-сплайн), касательные к лопатке и к полотну.

## Распознанные параметры
- Сектор 30° (12 пар лопаток: основная + укороченная).
- Полотно: поверхность вращения, толщина ≈1.07 мм, входная кромка полотна — полное скругление R≈0.54 мм.
- Срез лопаток и галтелей на выходе: цилиндр R = 128.46 мм; обод полотна R = 129.46 мм.
- Периферия (торцы лопаток): поверхность вращения, общая для обеих лопаток.
- Галтели: постоянный радиус **R = 2.5 мм** (по STL: 2.45…2.56 мм).
- Лопатки переменной толщины (≈0.6…2.3 мм), скруглённая несимметричная входная кромка.

## Точность (отклонение STL ↔ модель)
- Поверхности лопаток: среднее 0.003–0.005 мм, максимум 0.04 мм.
- Галтели: основная лопатка ≤0.03 мм; укороченная — среднее 0.02 мм, локально до ~0.35 мм у входной кромки.
- Вся модель: среднее 0.008 мм, 99% точек STL в пределах 0.043 мм.
- Объём: 12.51 см³ (STL — 12.50 см³).

Примечание: в исходном STL были продублированы внутренние грани (стык лопаток с полотном); при обработке они удалены.
